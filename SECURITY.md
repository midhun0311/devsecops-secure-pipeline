## Security Policy

### Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅ Yes    |

### Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public GitHub issue**.

Instead, email the maintainer directly (add your email here) with:
- A description of the vulnerability
- Steps to reproduce
- Potential impact

You will receive an acknowledgement within 48 hours and a resolution timeline within 7 days.

### Scope

This is a portfolio/educational project. Findings related to the intentional demo branch (`demo/vulnerable-change`) are expected and by design.
